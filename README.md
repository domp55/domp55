### 🧑‍💻 Sobre mí

- 🎓 Ingeniero en Ciencias de la Computación (**UNL**) y maestrante en **Ciberseguridad** (**UTE**).
- 🛠️ Desarrollo aplicaciones web y móviles de punta a punta: backend, frontend, nube y operación.
- 🔐 Me interesa el desarrollo seguro: cada sistema pasa por una auditoría de seguridad antes de salir a producción.
